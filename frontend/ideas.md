# 前端设计思路 - 人员定位监控系统

## 1. 设计理念：工业赛博朋克 (Industrial Cyberpunk)

### 核心原则
- **数据可视化优先**: 核心是地图和实时数据，界面应最大化展示这些内容。
- **高对比度**: 使用深色背景配合高亮强调色，确保在各种光照环境下清晰可见。
- **模块化布局**: 采用卡片式设计，方便不同分辨率屏幕的适配。
- **即时反馈**: 所有操作都有明确的视觉反馈，报警信息必须醒目。

### 色彩哲学
- **背景**: 深空灰 (#0f172a) 到 黑色 (#020617) 的渐变，营造科技感。
- **主色**: 霓虹蓝 (#3b82f6) 用于正常状态和交互元素。
- **报警色**: 
  - 紧急: 霓虹红 (#ef4444)
  - 警告: 琥珀黄 (#f59e0b)
  - 提示: 翡翠绿 (#10b981)
- **文字**: 纯白 (#ffffff) 用于标题，浅灰 (#94a3b8) 用于次要信息。

### 布局范式
- **全屏地图底座**: 地图作为整个应用的背景层，其他面板悬浮于上。
- **侧边栏导航**: 左侧收缩式导航，节省水平空间。
- **右侧信息面板**: 右侧可折叠面板，展示详细信息和操作表单。
- **底部状态栏**: 展示系统状态、连接状态和简要统计。

### 交互哲学
- **悬停即现**: 鼠标悬停在地图元素上显示简要信息，点击显示详情。
- **拖拽操作**: 电子围栏绘制、摄像头标定支持直观的拖拽操作。
- **快捷键**: 支持常用操作的快捷键（如报警处理、视图切换）。

### 动画效果
- **平滑过渡**: 面板展开/收起使用弹簧动画。
- **脉冲效果**: 报警点位使用脉冲动画吸引注意。
- **数据流**: 实时数据更新时有微小的闪烁或流动效果。

### 字体系统
- **标题**: 'Orbitron', sans-serif (科技感宽体字)
- **正文**: 'Inter', sans-serif (高可读性)
- **数据**: 'JetBrains Mono', monospace (等宽字体，方便对齐)

## 2. 关键页面设计

### 登录页
- 背景：动态粒子网格或工厂3D线框图。
- 登录框：半透明磨砂玻璃效果，居中悬浮。

### 实时监控 (主页)
- 全屏地图，支持缩放和平移。
- 左上角：搜索栏和图层控制。
- 右上角：报警通知中心。
- 左下角：实时测距工具和比例尺。
- 人员图标：根据工种显示不同颜色/图标，移动时有平滑动画。

### 电子围栏管理
- 列表模式和地图模式切换。
- 绘制工具栏：多边形、矩形、圆形绘制工具。
- 属性编辑面板：设置围栏类型、报警规则。

### 摄像头标定
- 分屏设计：左侧视频流，右侧地图。
- 对应点选取：点击视频画面和地图位置，自动连线示意。

### 报警中心
- 瀑布流或时间轴布局展示报警事件。
- 点击报警卡片弹出详情模态框（包含抓拍图、位置、处理记录）。

## 3. 组件库选择
- **基础组件**: shadcn/ui (基于 Radix UI)
- **图标**: Lucide React
- **地图**: Leaflet + React-Leaflet
- **图表**: Recharts
- **动画**: Framer Motion
- **表单**: React Hook Form + Zod

## 4. 响应式策略
- **桌面端 (Desktop)**: 完整功能，多面板布局。
- **平板 (Tablet)**: 侧边栏默认收起，面板半屏显示。
- **移动端 (Mobile)**: 底部导航，面板全屏弹出，地图简化显示。
